Run the demo

Simulated mode: no real calls are made. CALL-E's side of the call is scripted, and everything else really runs: the CRM is a separate service on :8001, and the guards, webhook, verification, rules and outbox are real code. Suggested order for the interview: 1 → 2 → Results tab → 4 → 5.

Step 1

Start fresh

Reseeds the CRM with 8 fictional customers and clears call history.

Terminal equivalent
curl -X POST localhost:8000/api/reset
Step 2

Run the reminder campaign

Reads all accounts from the CRM and checks each one before dialing. 6 calls go to CALL-E. 2 are blocked: one has no phone, one is do-not-call.

Terminal equivalent
curl -X POST localhost:8000/api/campaign -H 'content-type: application/json' -d '{}'
Step 3

See what happened

Results arrive about 3 seconds later through the webhook. Open the Results tab, and click a call to read the transcript, the extracted result, and what the CRM stored.

Open CRM :8001 ↗
Step 4

Break the integration

Places a call, then takes the CRM down before the result comes back. Expected result: the call shows crm_sync_failed, the outbox has 1 pending item, and nothing claims success.

Terminal equivalent
curl -X POST localhost:8000/api/outage-scenario
Step 5

Recover

Restores the CRM and re-sends the pending write. The CRM confirms with 201, and exactly one task is created.

Terminal equivalent
curl -X POST localhost:8000/api/crm/restore-and-retry
Manual controls

CRM failure switch

Inject failures by hand. A timeout makes the CRM answer after 6 seconds, so the orchestrator gives up after 3.

Terminal equivalent
curl -X POST localhost:8000/api/crm/failure -H 'content-type: application/json' -d '{"mode":"error"}'
curl -X POST localhost:8000/api/outbox/retry

Simulate one conversation

Each button runs one simulated call for María Fernanda (ACC-1001) with a scripted customer. These are the same conversations you can act out yourself on the "Call my phone" tab.

Terminal equivalent
curl -X POST localhost:8000/api/simulate -H 'content-type: application/json' -d '{"scenario":"promise_ambiguous"}'

Call my phone with real CALL-E

This places a real phone call from CALL-E to your phone. You play the customer, María Fernanda López García. The agent ("Sofía") will speak Spanish, confirm your name, remind you of the fictional $2,450 MXN installment, and ask when you'll pay. Each call uses CALL-E credits; new accounts get 100 free credits.

Step 1 · CALL-E dashboard

Get an API key

  1. Sign up or log in at heycall-e.com.
  2. Open Dashboard → Account → API keys and create a key.
  3. Paste it below. It's kept in this server's memory only. Add CALLE_API_KEY=… to .env to keep it across restarts.
Step 2

Your phone

Mexico uses an international line on CALL-E, so the caller ID may show a foreign number. Countries marked "not on CALL-E's list" are offered for testing; CALL-E will most likely reject them.

Step 3

Place the call

Terminal equivalent
curl -X POST localhost:8000/api/live/key -H 'content-type: application/json' -d '{"api_key":"YOUR_KEY"}'
curl -X POST localhost:8000/api/live/call-me -H 'content-type: application/json' \
  -d '{"phone":"+52XXXXXXXXXX","region":"MX","locale":"es-MX","timezone":"America/Mexico_City","consent":true}'
curl -X POST localhost:8000/calls/CALL_ID/sync      # repeat until "processed"
